# 布林带平行度：积分拟合算法

## 1. 问题背景

原算法用两点差分计算布林带轨道斜率，只取窗口首尾两个点，中间数据完全忽略。
存在两个缺陷：

- **噪声敏感**：窗口内单日异常波动不会被捕捉，首尾碰巧接近就误判为"水平"
- **量纲混搭**：斜率（价格/天）直接除以中轨（价格），虽然数学上成立但不够直观

## 2. 算法设计

### 核心思路

用**线性回归（最小二乘拟合）**替代两点差分，让窗口内所有数据点参与斜率计算；
再用**百分比归一化**使结果跨品种可比。

### 2.1 回归斜率

对窗口内 n 个等间距数据点 `(xᵢ, yᵢ)` 做线性回归：

```
斜率 = Σ(xᵢ - x̄)(yᵢ - ȳ) / Σ(xᵢ - x̄)²
```

x 为等间距时间序列，中心化后 `x̄ = 0`，ȳ 项自动消去：

```
斜率 = Σ(xᵢ · yᵢ) / Σ(xᵢ²)
```

`Σ(xᵢ²)` 有闭式解：

```
Σ(xᵢ²) = n(n² - 1) / 12
```

**n = 3（默认）时：**

```
x = [-1, 0, 1]
Σ(xᵢ²) = 1 + 0 + 1 = 2

斜率 = (-y₀ + y₂) / 2
```

**n = 5 时（对比）：**

```
x = [-2, -1, 0, 1, 2]
Σ(xᵢ²) = 4 + 1 + 0 + 1 + 4 = 10

斜率 = (-2y₀ - y₁ + y₃ + 2y₄) / 10
```

### 2.2 百分比归一化

回归斜率除以窗口内轨道均值，得到"每天百分之几"的变化率：

```
百分比斜率 = 回归斜率 / 窗口均值(y)
```

上轨和下轨各自独立计算，互不影响。

### 2.3 total_tilt 合成

```
total_tilt = |上轨百分比斜率| + |下轨百分比斜率|
```

含义：上下轨每天合计移动轨道均值的百分之几。
值越小越接近水平。

## 3. 与原算法对比

| 维度 | 原算法（两点差分） | 新算法（积分拟合） |
|------|------------------|-------------------|
| 数据利用 | 仅首尾两点 | 窗口内全部点 |
| 噪声抗性 | 差（中间波动被忽略） | 好（加权平滑） |
| 归一化方式 | 斜率÷中轨（共用分母） | 斜率÷各自均值（独立分母） |
| 量纲含义 | (价格/天)/价格 | (价格/天)/价格 |
| 结果稳定性 | 首尾敏感 | 全局拟合，稳定 |

### 数值对比示例

上轨 5 天：5100, 5150, 4900, 5130, 5120

```
两点差分：  (5120 - 5100) / 4 = 5.0
线性回归：  (-2×5100 - 5150 + 5130 + 2×5120) / 10 = 2.0
```

中间暴跌到 4900 被回归算法纳入了计算，两点差分完全无视。

## 4. 参数设计

| 参数 | 键名 | 默认值 | 含义 |
|------|------|--------|------|
| 周期单位时间数 | `slope_window` | **3** | 回归窗口长度（K线根数） |
| 平行度阈值 | `tilt_threshold` | 0.008 | total_tilt < 此值判定为水平 |

`slope_window` 作为可调参数暴露在面板上，用户可调整回归拟合的时间维度。

## 5. 代码实现

```python
def calc_regression_slope(values, i, window=3):
    """对 [i-window+1, i] 窗口做线性回归，返回斜率。
    
    利用中心化坐标化简为加权求和，O(n) 复杂度。
    """
    if i < window - 1:
        return None

    y = values[i - window + 1 : i + 1]
    n = len(y)
    center = (n - 1) / 2

    numer = sum((j - center) * y[j] for j in range(n))
    denom = n * (n * n - 1) / 12

    return numer / denom
```

total_tilt 计算：

```python
if i >= slope_window + bb_period:
    up_slope = calc_regression_slope(upper, i, slope_window)
    lo_slope = calc_regression_slope(lower, i, slope_window)

    up_mean = np.mean(upper[i - slope_window + 1 : i + 1])
    lo_mean = np.mean(lower[i - slope_window + 1 : i + 1])

    up_pct = abs(up_slope) / up_mean if up_mean > 0 else 999
    lo_pct = abs(lo_slope) / lo_mean if lo_mean > 0 else 999

    total_tilt = up_pct + lo_pct
else:
    total_tilt = 999
```

## 6. 注意事项

- 阈值 `tilt_threshold = 0.008` 是用原算法校准的，更换后可能需要微调
- 窗口越小越敏感、噪声越大；窗口越大越平滑、反应越慢
- 默认 3 个周期单位是平衡点，实际可通过面板调整
